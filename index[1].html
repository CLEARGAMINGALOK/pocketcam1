GitHub Pages hosts this static site over HTTPS, which supports camera permissions. The browser uses PeerJS Cloud as a signaling broker and WebRTC for media. This is a community/demo approach, not a guaranteed production service. Bluetooth is not used. USB tethering can provide network connectivity, but does not create a system-wide webcam or microphone device. OBS can capture the PC viewer page as a Browser Source.
